# BuildFlow AI — User Personas & Journeys

## Personas

### 1. Company Owner
**Goal:** Understand the financial and operational health of the construction business.

**Needs:** Portfolio dashboard, profitability, budget variance, project status, team visibility.

**Success:** Can identify which projects need attention without opening every project.

### 2. Project Manager
**Goal:** Deliver projects on time and within budget.

**Needs:** Tasks, milestones, risks, documents, progress, procurement, reporting.

**Success:** Can understand today's priorities and project blockers from one workspace.

### 3. Quantity Surveyor
**Goal:** Maintain cost control and commercial accuracy.

**Needs:** BOQ, rates, valuations, variations, cost codes, forecasts.

**Success:** Can update and analyze project costs without maintaining disconnected spreadsheets.

### 4. Site Engineer
**Goal:** Record and communicate field progress.

**Needs:** Site diary, photos, tasks, issues, equipment, daily reports.

**Success:** Can submit a complete daily update quickly from the field.

### 5. Procurement Officer
**Goal:** Ensure materials and services arrive when required at controlled cost.

**Needs:** Suppliers, RFQs, purchase orders, deliveries, procurement status.

**Success:** Can trace a material requirement from request to delivery.

### 6. Finance Officer
**Goal:** Maintain reliable project financial visibility.

**Needs:** Budgets, actuals, invoices, payment status, cost reports.

**Success:** Can reconcile project financial activity and identify exceptions.

### 7. Client
**Goal:** Understand project progress and approve required items.

**Needs:** Progress, reports, documents, approvals, selected financial visibility.

**Success:** Can see trustworthy project information without accessing internal operational data.

## Core Journeys

### Journey A — Company Onboarding
Sign up → create organization → choose role → complete company profile → invite teammates → create first project → land on dashboard.

### Journey B — Project Creation
Dashboard → New Project → project details → client → dates → budget → team → create → project overview.

### Journey C — QS BOQ Workflow
Project → BOQ → create section → add line items → quantities/rates → deterministic totals → review → publish/version → cost dashboard.

### Journey D — Site Diary
Project → Site Diary → select date → weather/site conditions → labour/equipment → progress → photos → issues → save → notify project team.

### Journey E — Procurement
Project → Procurement → create purchase request → review/approve → supplier → purchase order → delivery → mark received → link cost.

### Journey F — AI Assistance
Project → AI Assistant → user asks question → system retrieves authorized project context → AI generates response → sources/context shown where possible → user can copy/save result.

### Journey G — Project Health
Dashboard → select project → project health → budget/schedule/task/procurement indicators → identify risk → open relevant module → take action.
